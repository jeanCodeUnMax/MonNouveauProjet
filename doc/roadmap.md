# Roadmap – MonNouveauProjet

## Objectif global
Restructurer le projet pour intégrer des notebooks Google Colab contenant les scripts LamaCCP, avec activation/désactivation, manifests pour mémoire unifiée entre sessions, et optimisation GPU au démarrage et à l'arrêt.

## Phases principales

### Phase 1 – Préparation des notebooks Colab
- Créer les notebooks Google Colab
- Intégrer les scripts LamaCCP
- Définir la structure de base des notebooks

### Phase 2 – Activation et désactivation
- Mettre en place les mécanismes d'activation
- Mettre en place les mécanismes de désactivation
- Gérer le cycle de vie des sessions

### Phase 3 – Manifests et mémoire unifiée
- Créer les manifests
- Assurer la persistance de la mémoire unifiée entre sessions
- Gérer le chargement et la sauvegarde des états

### Phase 4 – Optimisation GPU
- Optimiser le démarrage (startup)
- Optimiser l'arrêt (shutdown)
- Maximiser l'utilisation du quota GPU gratuit

### Phase 5 – Documentation et intégration finale
- Finaliser la documentation dans le dossier `doc`
- Découper en issues et sous-tâches
- Mettre à jour le README principal
